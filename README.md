# West Bengal Assembly Election 2026 Analysis

## Project Overview

This project presents an interactive political analytics dashboard built using Power BI and Excel to analyze the West Bengal Assembly Election 2026 results at the constituency level.

The dashboard focuses on:
- Party-wise seat distribution
- Victory margin analysis
- Closest electoral contests
- Largest winning margins
- Region-based political insights
- KPI-driven election overview

The objective of this project is to transform raw election result data into structured analytical insights using data cleaning, transformation, and visualization techniques.

---

## Tools Used

- Microsoft Excel
- Power BI Desktop

---

## Dataset Source

Source: Election Commission of India (ECI)

Election result data was collected and transformed for analytical purposes.

---

## Features of the Dashboard

### Election Overview KPIs
- Total Seats
- Winning Parties
- Average Victory Margin
- Maximum Victory Margin
- Average Winner Vote Share %

### Party-wise Seat Distribution
Visual representation of seats won by different political parties.

### Largest Victory Margins
Top constituencies with the highest winning margins.

### Closest Electoral Contests
Constituencies with the narrowest victory margins, indicating highly competitive races.

### Region-Based Filtering
Interactive slicers allowing analysis across different political regions of West Bengal.

---

## Data Preparation Process

The project involved:
- Cleaning raw constituency-level election data
- Standardizing party names
- Structuring winner and runner-up datasets
- Calculating victory margins
- Creating analytical tables for dashboarding

---

## Key Insights

- BJP emerged as the dominant party in terms of seat share.
- Several constituencies witnessed extremely close contests with margins below 1,000 votes.
- Regional political variation was visible across North Bengal, Junglemahal, and Kolkata regions.
- Margin analysis highlighted both highly competitive and strongly polarized constituencies.
